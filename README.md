# weak-nilpotence-engel
This repo contains the Macauley2 code that is used to check the main claims of the paper "On a conjecture of Dotsenko on weak nilpotence and the Engel identity."
The contents of this repo are as follows:
1. A verify_e7.m2 script: this checks the t_4=0 identity for the algebra A appearing in the paper.
2. A verify_e8.m2 script: this checks the  t_4=0 identity for the algebra A appearing in the paper.
3. A verify_e9.m2 script: this is a machine readable script showing that the 9-Engel identity can be deduced from the t_4=0 identity.
4. A verify_e14.m2 script: the algebra appearing in this script is mentioned indirectly in the paper. It is a 111 dimensional example of a algebra statisfying t_5=0 which is not 14-Engel.
5. main.pdf is the paper itself.
